# RunProof 5 分钟演示脚本（录屏 / 现场通用）

> 定位一句话：**RunProof 不是游戏世界纪录榜，而是任何"可量化成绩"的链上排行榜**——Minecraft 速通时间、
> 一秒点击次数、引体向上个数、考试成绩，只要能量成一个整数，就能上榜，而且成绩真假由社区投票判定，
> 不由平台说了算。

## 二、分镜脚本（可直接照念）

### 0:00 – 0:40　先说问题（画面：榜单页即可，不要念 PPT）

"现在的成绩排行榜都是各管一摊：速通在 speedrun.com，手速在别的网站，健身记录在某个 App 里。
它们的共同问题是一样的——**你没法证明这个成绩没造假**。平台说你作弊，你就下榜；平台删你记录，
你连申诉的证据都拿不出来。"

### 0:40 – 1:20　是什么（画面：切分类标签，指出单位/方向）

"RunProof 是一个通用的链上成绩排行榜。管理员只做一件事：开分类——定单位，定是越高越好还是越低越好。
比如 `Minecraft Any%` 用毫秒、越低越好；`Click Speed` 用每秒点击数、越高越好。
然后**任何人**都能提交成绩，**排名由合约算，不由平台算**。"

顺手点一下 `Bedrock` division："同一个分类下还能分服、分版本，互不干扰。"

### 1:20 – 2:20　演提交（画面：榜单页 → 提交交易）

"比如这条 `19:12.345`——注意链上存的是毫秒整数 `1152345`，不存浮点数，从根上避免精度问题。
提交要付基础质押；如果成绩比当前榜首更好，合约会自动要求更高的质押，想抢第一押的钱也得多。
提交后有 60 秒挑战期，没人质疑就自动认证，进正式榜单。"

指右侧："这里 `bestRecordId` 和榜单第一名一直是对账的——链上说了算，不是数据库说了算。"

### 2:20 – 3:40　演撤销（全场重点，画面：交易详情 → 回到榜单）

"现在有人提交了 `18:59.999`，直接登顶。但举报说视频剪过。

任何人可以质押发起挑战，然后进匿名投票：先提交哈希承诺，到时间再揭示——**防止看别人怎么投再跟票**。
这次 5 个人投票，确认造假 400 票权、反对 100，80% 通过。合约判定造假，成绩撤销。

关键在这里——**榜首在同一个交易里自动回退到 `19:12.345`**，不需要管理员手动改榜。"

（画面停在这一条：`bestRecordId(4,1)` 从 9 变回 1。）

### 3:40 – 4:20　演钱和 NFT（画面：钱包余额 / NFT 状态）

"钱也是合约算的：投对的人拿回质押 + 奖励，每人从 0.1 变成 0.2075；投错的那个人被罚没，只剩 0.007；
挑战者因为提供了有效证据，余额从 0.42 涨到 1.31。

认证过的成绩可以铸 NFT，永远铸给成绩本人。#1 是有效的；#9 被撤销了，NFT 不销毁，但状态变成
`Revoked`——链上留痕，赖不掉。"

### 4:20 – 5:00　收尾（画面：合约源码页）

"现在跑在 Monad 测试网，四个合约，源码已经在浏览器上验证过，任何人都能读、能核对。
测试全过，包括不变量测试，资金偿付能力在随机 9600 次调用下没被破坏。

下一步是把事件索引成完整榜单和公共 API，让任何网站都能直接查——**成绩这件事，应该有一个中立的地方存着**。"

## 五、录屏时会撞的坑

1. **别现场等链上**：完整流程要 2 分半（60s 窗口 + 30s commit + 30s reveal），录屏用已经发生的数据讲，不要等。
2. **网络**：榜单页连的是 `https://testnet-rpc.monad.xyz`。如果页面一直"读取链上数据中"，先确认这台机器能访问该 RPC；
   WSL 里代理要指向 `127.0.0.1:7897`。
3. **字体**：页面用系统中文字体，Windows 浏览器正常；如果截图里全是方块，是录屏环境的字体问题，换本机录。
4. **窗口别缩小**：页面在 1160px 宽以上是两栏布局，右侧对账卡片是最有说服力的部分，别被切掉。
5. **说数字时给单位**：`1152345` 一定要说成"19 分 12 秒 345"，否则观众没有体感。

## 六、如果要现场演示（不只录屏）

最短路径（约 4 分钟，已实测可行）：

```bash
# 1. 提交一条成绩（换成你的分类/division）
cast send $CORE "submitRecord(uint256,uint256,uint256,bytes32,string)" 4 1 1150000 \
  $(cast keccak "live-demo") "ipfs://live-demo" --value <requiredPayment> --private-key ...

# 2. 等 60 秒，认证
cast send $CORE "finalizeRecord(uint256)" <recordId> --private-key ...

# 3. 榜单页 F5，指 bestRecordId 与第一名一致
```

现场不要演完整挑战流程（要 2 分半且容易卡在投票窗口），那段用录屏或已发生的交易讲。
