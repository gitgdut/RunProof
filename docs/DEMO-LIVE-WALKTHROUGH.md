# 网页现场操作演示（跑通即可）

公开网址：**https://gitgdut.github.io/RunProof/**

> 打开就能看（读链上数据，不需要任何东西）。要"写"（提交成绩）需要一个浏览器钱包
> （MetaMask / Rabby）+ Monad 测试网 MON。两条路都写在下面，按你手头的条件选。

---

## 路线 A：纯浏览演示（30 秒，零依赖，零风险）

不需要钱包，打开页面就能做，证明"榜单是链上实时算出来的"。

1. 打开 `https://gitgdut.github.io/RunProof/`，等 Dashboard 顶部出现
   `5 个通用赛道 · 9 条链上成绩`（这是实时读链，不是截图）。
2. 左侧点 **Leaderboard** → 顶部切到 `Minecraft Any%` + `Java`。
   指着第一名 `19:12.345 · 1152345 ms`，说"这是链上存证，不是平台数据库里的数字"。
3. **点击那条成绩** → 右侧弹出详情：玩家地址、`value`、证据哈希 `0x2010a8…`、
   质押、`Verified` 状态、挑战倒计时。说"证据的哈希存在链上，谁都能核对"。
4. 左侧点 **User Profile** → 粘贴任一地址（如 `0x0D64b1D9AbF6C30ced5e1edf325C3536086f32E7`）
   → 显示它的提交记录和可提取余额。
5. （可选）点 **Reason Registry** → 看 R001–R005 五个通用挑战理由。

**这一套能证明：读全通、数据来自链、详情可核验。** 如果评委只看不点，这 30 秒就够。

## 路线 B：现场提交一条成绩（约 2 分钟，需要钱包 + MON）

这是"写"链路，能证明项目端到端跑通。前置：

- 浏览器装 MetaMask 或 Rabby
- 钱包里加 Monad Testnet（chain `10143`，RPC `https://testnet-rpc.monad.xyz`）
- 领测试币：https://faucet.monad.xyz （把 MON 领到你的钱包，0.2 就够）

步骤（用 Click Speed 分类，数值取个不会冲击榜首的，省钱）：

1. 页面右上角点 **连接 EVM 钱包**，授权，确认切到 `10143`。
2. 点 **Submit Record**：
   - 分类 `Click Speed`，division `All`
   - 成绩填 `12.50`（单位 cps，精度 2，链上会存成 `1250`）
   - 证据随便填个 URI，或直接留演示值
   - 页面会显示 **requiredPayment ≈ 0.06 MON**（0.01 手续费 + 0.05 基础质押）和 gas 预估
3. 点确认 → 钱包签名 → 交易上链。
4. 回到 Dashboard / Leaderboard：这条成绩以 **Provisional（待认证）** 出现，但**不在正式榜**。
   说："它进了待认证队列，但还不能上正式榜。"
5. 等 **60 秒挑战期**结束（就靠这 60 秒给观众讲机制），点 **finalize**（详情面板里）
   → 状态变 **Verified**，刷新后它进入 `Click Speed` 正式榜。
6. 想更完整：对这条成绩点 **mint NFT**，或到 User Profile 看自己可提取的质押。

**这一套能证明：连接钱包 → 提交 → 上链 → 挑战期 → 认证 → 进榜，全链路跑通。**

> 时长把控：提交 + 60s 等待 + finalize ≈ 2 分钟。讲解语速放慢正好填满。
> 如果现场网络慢，60 秒等待期就是你讲"挑战期 + Commit-Reveal 投票"的黄金时间，别浪费。

## 现场最可能翻车的地方（提前排雷）

| 坑 | 怎么办 |
|---|---|
| 钱包切不过去 10143 | 手动在 MetaMask 加网络：Chain ID `10143`、RPC `https://testnet-rpc.monad.xyz`、币种 `MON` |
| 没有 MON | 现场就切到路线 A；别现场领水龙头（排队/失败都难看） |
| `requiredPayment` 显示 0 或报错 | 页面读取被 RPC 限流，F5 重试一次 |
| 提交后记录没立刻出现 | 等 2–3 秒再刷新，事件索引要一个区块 |
| 钱包签名弹不出来 | 检查 MetaMask 是否锁定，或点"连接钱包"重新连 |
| 时间不够走完 60s | 只做到"提交成功、出现 Provisional"，然后说"60 秒后任何人可认证"，把 finalize 留到口头 |

---

## 一句话推荐

- 求稳：**只走路线 A**（30 秒，零风险，读全通）。
- 想证明"真能写"：**路线 B 只做第 1–4 步**（连接 + 提交 + 看到 Provisional），
  认证那步如果时间紧就口述"60 秒后自动可认证"。
- 完整撤销投票流程**不要现场做**（要 5 个钱包 + 2 分半），那条用视频讲。
