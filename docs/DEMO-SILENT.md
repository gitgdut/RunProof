# 无声视频 + 现场讲解方案（4:30 版）

> 视频不说话，靠画面文字叙事；现场播放时在 3 个固定点暂停，由你口播。
> 视频 **3:50** + 口播 **42 秒** = **4:32**，留 28 秒缓冲。

---

## 一、播放器已经做好了

**在线版（推荐，评审也能自己点开）**
https://gitgdut.github.io/RunProof/record.html

**本地版**
```bash
python3 -m http.server 8787     # 在仓库根目录
# 打开 http://127.0.0.1:8787/web/record.html
```

8 幕自动播放，带进度条和计时器。第 4 幕是**真实榜单页 iframe**（链上实时数据，不是截图）。

### 键盘控制

| 键 | 作用 |
|---|---|
| `空格` | 暂停 / 继续（现场讲解就用这个） |
| `←` `→` | 上一幕 / 下一幕（现场救场用） |
| `R` | 从第一幕重新开始（录屏前按一下） |
| `F` | 全屏 |

## 三、现场口播稿（照读，共 42 秒）

### ⏸ 0:45 暂停 · 讲 A（约 12 秒）

> 今天的成绩都锁在平台的数据库里——规则、审核、下榜，平台说了算。
> 我们要把这三样东西搬到链上：成绩、证据、还有判定过程。

### ⏸ 1:55 暂停 · 讲 B（约 12 秒）

> 这是我们链上的真实榜单，不是截图。
> 右边这一行是合约里的 bestRecordId 和榜单第一名对账，绿勾才表示一致——
> **排名不是我们算的，是合约算的。**

### ⏸ 3:10 暂停 · 讲 C（约 18 秒）

> 这条 18 分 59 秒是真实提交的，比榜首快 13 秒，先登顶了。
> 五个人匿名投票，确认票 400、反对 100，80% 通过，判定造假。
> 合约撤销这条成绩，**并在同一笔交易里把榜首退回 19 分 12 秒**。
> 没有管理员登录，没有后台改数据。

> 时间紧就砍 A（它最不关键），保留 B 和 C —— 6/2 秒也能撑住。

## 四、录屏操作（10 分钟，一遍过）

### 录制前

1. 浏览器打开 `https://gitgdut.github.io/RunProof/record.html`
2. **先单独开一次** `https://gitgdut.github.io/RunProof/`，等榜单数据出来再关掉 —— 让 iframe 走缓存，第 4 幕不会白屏
3. `F11` 全屏；`Ctrl+0` 把缩放归到 100%
4. Windows 打开「专注助手 / 勿扰」，关掉微信、邮件通知
5. 鼠标移到屏幕右下角（录不到鼠标更干净）

### 录制

1. `Win + Alt + R`（Xbox Game Bar）或 OBS 开始录，1080p / 30–60fps
2. 按一次 `R`，从第一幕重新开始（录制开头几秒剪辑掉即可）
3. **全程不说话、不点鼠标**，让它自己跑 3 分 50 秒
4. 到 3:50 最后一幕停住 → 停止录制

### 录完检查

- [ ] 总长 3:45–3:55
- [ ] 第 4 幕（1:15 起）榜单**有数据**，不是空白
- [ ] 第 6 幕的时间线文字完整（五条）
- [ ] 没有鼠标、没有通知弹窗、没有终端窗口

> **只有第 4 幕白屏才需要重录**，其他小瑕疵都能接受。

## 五、现场操作流程

```
1. 打开 record.html，F11 全屏
2. 按 R 重置到第一幕
3. 按空格开始（如果它已经在跑，直接等）
4. 到 0:45 → 空格暂停 → 讲 A → 空格继续
5. 到 1:55 → 空格暂停 → 讲 B → 空格继续
6. 到 3:10 → 空格暂停 → 讲 C → 空格继续
7. 3:50 结束，画面停在收尾页，开始 Q&A
```

**如果现场不给播视频**：直接打开 https://gitgdut.github.io/RunProof/ ，
用鼠标切分类（Java → Bedrock → Click Speed），把 A / B / C 三段话讲一遍，约 1 分半。

## 七、事故预案

| 情况 | 处理 |
|---|---|
| 视频打不开 / 播不出来 | 直接开公网榜单页，按"不给播视频"那套讲 |
| 第 4 幕 iframe 白屏 | 别停顿，直接讲 B（"这是实时读链上的，网络慢的时候就这样"），继续播放 |
| 忘了暂停点 | 看进度条：45 秒、1:55、3:10 三个位置 |
| 评委打断提问 | 直接空格暂停回答，答完继续，不要重播 |
| 时间被砍到 3 分钟 | 从第 5 幕开始播（按 `→` 三次），只讲 C |
